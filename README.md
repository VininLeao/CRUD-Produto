# 🛠️ CRUD de Produtos em C#

Este é um projeto simples de CRUD (Create, Read, Update, Delete) em C#, com interface de console, que permite gerenciar uma lista de produtos.

## 📋 Funcionalidades

- Adicionar um novo produto  
- Remover produto pelo ID  
- Editar produto pelo ID  
- Visualizar todos os produtos cadastrados  
- Encerrar a aplicação  

## ✅ Pré-requisitos

- [Visual Studio](https://visualstudio.microsoft.com/) (ou outra IDE com suporte a C#)  
- [.NET Framework](https://dotnet.microsoft.com/en-us/download/dotnet-framework) compatível  

## 🚀 Como executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/VininLeao/CRUD-Produto
   ```

2. Abra o projeto no Visual Studio:
   - Vá em **Arquivo > Abrir > Projeto/Solução**
   - Selecione o arquivo `.sln` na pasta clonada

3. Compile o projeto:
   - Pressione `Ctrl + Shift + B` ou vá em **Compilar > Compilar Solução**

4. Execute o projeto:
   - Pressione `Ctrl + F5` ou vá em **Depurar > Iniciar sem Depuração**

## 💻 Uso do sistema

Ao iniciar, uma janela de console será aberta com o seguinte menu:

```
1 - Adicionar Produto  
2 - Remover Produto pelo ID  
3 - Editar Produto pelo ID  
4 - Visualizar Todos os Produtos  
0 - Sair
```

Digite o número da opção desejada e siga as instruções no console.

## 📁 Estrutura do Projeto

```
CRUD-Produto/
├── Program.cs         # Ponto de entrada da aplicação
├── Produto.cs         # Classe de modelo do produto
├── ProdutoService.cs  # Classe com as funcionalidades do CRUD
```
